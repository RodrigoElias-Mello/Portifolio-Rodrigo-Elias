## 🚀 Sobre este projeto

Este repositório apresenta o código-fonte do meu portfólio profissional, desenvolvido para reunir minha trajetória, competências técnicas e projetos.

O projeto prioriza:

- Interface moderna e responsiva;

## ⚙️ Como executar localmente

Clone o repositório:

```bash
git clone https://github.com/RodrigoElias-Mello/Portifolio-Rodrigo-Elias.git
```

Entre na pasta:

```bash
cd Portifolio-Rodrigo-Elias
```

Instale as dependências:

```bash
pnpm install
```

Execute o projeto:

```bash
pnpm dev
```

Acesse `http://localhost:3000` no navegador.
