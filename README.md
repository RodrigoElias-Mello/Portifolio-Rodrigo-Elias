## 🚀 Sobre o projeto

Este repositório contém o código-fonte do meu portfólio profissional, desenvolvido para apresentar minha trajetória, competências técnicas, experiências e projetos na área de tecnologia.

Mais do que uma página de apresentação, o portfólio funciona como uma vitrine profissional dos trabalhos que desenvolvo, demonstrando minha capacidade de transformar necessidades e desafios em soluções digitais.

A aplicação foi construída com foco em uma experiência moderna, responsiva, acessível e intuitiva, valorizando a organização das informações, a identidade visual e a navegação.

## 🎯 Objetivos

- Apresentar minha trajetória profissional e acadêmica.

## 💻 Executando o projeto localmente

### Pré-requisitos

- Node.js 24 ou compatível.
- pnpm 12.3.4.
- Git.

### 1. Clone o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 2. Acesse a pasta do projeto

```bash
cd Portifolio-Rodrigo-Elias
```

### 3. Instale as dependências

```bash
pnpm install
```

### 4. Execute em ambiente de desenvolvimento

```bash
pnpm dev
```

### 5. Acesse no navegador

```text
http://localhost:3000
```

### 6. Gere a versão de produção

```bash
pnpm build
```

### 7. Execute a aplicação em produção

```bash
pnpm start
```
